使用說明

基本流程

  1. 點擊「新增工作階段」上傳一張測試桌面圖片
  2. 系統會模擬視覺偵測，標記圖片中的物件並計算 3D 座標
  3. 在聊天室輸入自然語言指令 (如：「夾起紅色積木放到藍色盒子」)
  4. AI 解析指令並生成機械手臂動作序列
  5. 點擊執行模擬，查看即時日誌並下載指令記錄

AI 協助面板

  • 指令設計師：協助優化自然語言以獲得更好的解析結果
  • 任務規劃師：討論多步驟任務分解策略
  • 座標除錯器：解釋像素到世界座標的轉換過程
  • 代碼生成器：從模擬日誌匯出 Python/ROS 代碼

標準動作庫

detect(target_name)  - 視覺偵測物件
pick(x, y, z)        - 移動至座標並夾取
place(x, y, z)       - 移動至座標並放置
reset_home()         - 回到安全初始位置

隱私權與使用條款

資料收集

本平台僅收集運作所需的最少資料：帳號資訊、聊天訊息、上傳圖片、模擬日誌。

AI 處理

自然語言指令會傳送至 Azure OpenAI / GitHub Models 進行解析，不包含個人身分資訊。

資料儲存

所有資料儲存於 Supabase (PostgreSQL)，您可隨時要求刪除帳號與資料。

教育用途

本平台專為教育測試設計，非生產級機器人控制系統。模擬結果僅供學習參考。
